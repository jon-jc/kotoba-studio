# Agent Note: 语音选择与模型准备反馈

Status: implemented

[English](2026-09-10-voice-selection-and-model-progress.md) | 中文

## Problem

用户滚动面板时，滚轮会更改语音标签页和模型选项。大型语音模型下载缺少传输与加载进度提示。

## Decision

原生语音标签栏和关闭的下拉框忽略滚轮输入，同时保留点击和键盘选择。模型准备通过排队的 Qt 信号报告每次操作的进度。Parakeet 在校验和验证与解压之前报告压缩包字节数；Whisper 使用固定版本的 faster-whisper 注册表和 Hugging Face 快照回调。总量未知时显示不定进度。界面仅在加载成功后报告完成，并在失败时清除进度。

根目录产品 README 保留英语和日语导航。中文版本仍接受内容一致性检查，但产品首页不强制显示中文切换链接；其他手写文档仍遵循现有切换链接要求。

## Alternatives considered

**基于估计时间的百分比** 无法准确反映慢速下载与模型加载。进度改为使用实际字节数或文件数。

**全局下载钩子** 会影响并发调用方。每次快照操作使用独立回调类。

## Consequences

用户可以滚动而不改变智能体配置，并能区分下载和本地加载。现有缓存、离线和校验和规则保持有效。仅提供文件进度的 Hugging Face 版本显示文件数；准备过程不承诺剩余时间估计。针对性测试覆盖滚轮输入、键盘选择、字节报告、未知总量、排队的界面更新和失败恢复。

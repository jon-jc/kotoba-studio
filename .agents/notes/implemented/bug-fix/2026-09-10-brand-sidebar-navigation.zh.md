# Agent Note: 品牌按钮打开工作区侧边栏

Status: implemented

[English](2026-09-10-brand-sidebar-navigation.md) | 中文

## Problem

工作区侧边栏属于嵌入式聊天页面，选择原生代码或设置面板后会被隐藏。桌面品牌栏未提供打开侧边栏的入口。

## Decision

左上角图标与名称组成可访问按钮，切换到保留的聊天页面并展开其现有侧边栏。桥接使用侧边栏的本地化可访问标签，仅点击折叠状态下的控件。有界重试适应异步启动；离开聊天页后停止后续尝试。代码标签页、终端输出和语音草稿仍由原有面板持有。

## Alternatives considered

**重新加载聊天页面** 会丢弃临时界面状态并重复启动。按钮改为显示现有页面。

## Consequences

用户可以从每个原生面板访问侧边栏，无需创建第二套导航。桥接依赖现有侧边栏的可访问标签；桌面工作流测试以及真实英语和日语代码面板到侧边栏的检查覆盖导航和状态保留。

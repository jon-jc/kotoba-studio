# Agent Note: 代码工作区导航

Status: implemented

[English](2026-09-10-code-workbench-navigation.md) | 中文

## Problem

已选中的代码按钮无法关闭其页面。空查看器显示未使用的搜索控件，工作区导航与文件内容也缺少清晰区分。

## Decision

代码按钮可切换回聊天，并提供本地化关闭操作。Escape 先关闭搜索，再离开代码页；Ctrl+W 关闭文件或离开空页面。切换页面保留已打开文件。资源管理器、工作区相对路径、源码标签页和紧凑状态栏分区显示。搜索仅在请求时显示，无文件时不可用。空状态提供文件夹选择入口。现有只读、UTF-8、大小限制和语法高亮行为保持有效。

## Alternatives considered

**关闭页面时丢弃标签页** 会让导航具有破坏性，并迫使用户重新打开工作上下文。关闭代码页仅更改所选面板。

## Consequences

用户可以通过工具栏或键盘离开代码页，并返回相同文件。关闭文件仍会释放其编辑器。原生工作流测试覆盖导航、标签页保留、搜索关闭和最后一个标签关闭后的空状态；视觉检查覆盖两种语言和键盘操作。

# Agent Note：订阅代理工作区

Status: implemented

[English](2026-09-12-subscription-agent-workspace.md) | 中文

## 问题

Kotoba 需要在一个桌面工作流中提供订阅编码代理、独立任务工作树和审查，同时保留完整 API Harness 和双语语音工具。Orca 的 Web 账户 API 未完整实现桌面账户管理。

## 决策

将 Orca 1.4.197 固定为子模块，在临时检出目录构建完整 Electron 界面和原生服务。将所拥有的 Windows 窗口嵌入 Qt。Agents 成为主工作区，API 聊天仍可独立访问。限当前用户访问的命名管道仅接受项目、导航、快照和已审阅草稿操作。管道客户端 PID 和原生窗口 PID 都必须匹配所拥有的 QProcess，回复必须携带每次启动生成的随机标识。

选定的本地工作树更新代码和语音上下文；正在运行的语音任务保留原始根目录。远程路径不会成为本地路径。插入草稿要求兼容且为空的原生聊天输入框，绝不自动发送。底层 CLI 管理自身权限、身份验证和订阅额度。Harness 权限仍独立，Access 按钮跟随当前工作区。

构建覆盖层隔离配置目录，禁用遥测和上游本地更新器，去除重复托盘及窗口控件，保留正常 CLI 启动审批默认值，并应用 Kotoba 外观和语言。保留上游许可文件和运行时依赖资源。打包使用上游原生 PTY 所有权、守护进程加载、CLI 资源和内置插件探针；只有验证通过才发布产物。

## 考虑的替代方案

单独的 Orca 窗口会拆分所要求的工作流。其 Web 客户端缺少原生账户管理操作。重新实现原生代理启动、PTY 和审查代码会重复大量现有实现。通用 JavaScript 桥接会暴露不必要的权限；固定命令词汇已足以共享上下文和审阅后的文本。

## 影响

桌面包含具有不同账户和权限契约的两个代理引擎。订阅代理为主，API 会话保留独立历史。公开 README 在一个文件中包含英语和日语，不再遵循继承的中文配对要求。上游子模块使用自己的 lint 工具链。

## 验证与限制

定向测试覆盖产物路径限制、环境过滤、外部回复和窗口、过期上下文、草稿拒绝、主导航和运行中任务的目录保持。隐藏的 Windows 冒烟测试启动打包后的原生窗口，添加临时 Git 项目，读取选定工作树并拒绝不可用的草稿。未执行付费提供商调用、远程主机、账户配置和外部发布。嵌入运行时当前面向 Windows x64；签名、干净机器资格验证及广泛外部服务覆盖仍属于独立发布工作。

## 嵌入显示修正（0.10.1）

Qt 接管 HWND 后不会更新 Electron 的隐藏窗口合成状态。固定的 `present` 操作只显示已经嵌入且可见的工作区，不激活窗口，同时关闭渲染器后台节流并请求合成帧。原生 Qt 容器将子窗口重新定位到自身原点，并轻微调整尺寸后恢复，以修正 Electron 恢复旧顶层坐标和保留过期画面的问题。隐藏事件也同步到 Electron。重新显示代理页面时再次执行交接。账户导航确认成功并报告失败；首次引导在设置页面暂时隐藏，不会将引导标记为完成。

隐藏的 IPC 冒烟测试无法验证合成像素。`smoke_fleet_display.py` 提供显式启用的 Windows Graphics Capture 检查，使用隔离配置和自有进程清理，验证工作区渲染、账户页面切换、调整尺寸和隐藏后恢复。可选捕获依赖仅用于验证；截图可能包含本地账户标签，因此不提交到文档。

## 代理访问与移动端移除（0.10.2）

覆盖层用按代理设置的计划、审批和工作区编辑取代全局绕过开关。Codex 使用沙箱与升级参数；Claude 使用原生工具审批模式。OpenCode 内联配置覆盖全局及内置 Plan/Build 权限，保留环境文件读取保护和命令审批。未知或自定义配置不会被标记为已实施的限制。现有会话及不支持的代理保留自身权限契约。旧的精确绕过预设迁移到正常审批默认值，自定义参数不被覆盖。

Kotoba 禁用移动导航、外观入口、配对 IPC、桌面推送和云中继启动。固定的上游源代码保持不变。定向测试覆盖权限映射、冲突参数、配置保留和自定义状态；原生桌面检查验证设置导航。

## 统一导航（0.11.0）

固定左侧栏区分主要工具、协作与配置。桌面页头仅保留当前页面、项目选择、命令搜索和语言。隐藏的兼容按钮保留桥接契约，重复的 Fleet 操作栏被移除；远程上下文和失败提示仍可见。原生运行时使用统一的中性色和尊重减少动画偏好的过渡。连接页面分别提供订阅账户、API 提供商和本地模型入口。关闭音频面板保留下稿，切换 API 会话不会停止其他会话。

定向桌面测试覆盖 1024 像素下英日双语页头布局、API 导航、音频草稿保留、从代码页打开账户以及切换语言后的项目名称。Windows Graphics Capture 验证完整桌面合成画面。

## 产品界面清理（0.11.1）

Kotoba 不再显示自动或显式请求的 Orca CLI 推广提示。移除 Orca Account 导航、页面和意外退出登录推广卡片；旧账户链接转向 AI Provider Accounts，保留编码代理登录。桌面介绍改为说明双语语音、代理开发和会议交接。语音选择框统一高度、内边距和自定义箭头。专项推广测试与打包后的访问权限冒烟测试覆盖移除的界面和保留的账户导航。

## 侧边栏与 Windows Codex 检测（0.11.2）

帮助菜单移除上游反馈、里程碑、入门、文档、更新日志及社交链接，并停止预加载反馈对话框。Windows 代理检测支持桌面 Codex 版本缓存中的有效可执行文件，保留显式 PATH 安装的优先级。启动和刷新会追加检测到的目录，使终端启动与检测一致。查找有范围限制，忽略未完成下载且不执行二进制文件。测试覆盖空 GUI PATH、更新安装、重定向 LocalAppData、选择优先级和菜单移除。


## 原生键盘与显式代理聊天（0.12.1）

嵌入的 Chromium 子窗口可能具有 DOM 焦点，但 Win32 键盘焦点仍停留在 Qt 外层窗口。可信主框架的指针操作通过带启动随机值的运行时标准输出请求焦点交接。Qt 再次检查进程所有者、前台根窗口和子窗口关系后才调用 SetFocus。隐藏、后台及分离窗口不能取得焦点；Tab 导航使用相同路径。应用不合成按键，轮询不会改变焦点。

新建的受支持会话默认使用原有会话传输。一次性迁移升级旧默认值，之后保留用户选择及现有会话。New chat 菜单提供 Codex、Claude 的聊天及终端选项，每次启动仅覆盖当前显示方式，保留账户、权限参数、工作区和其他会话。Agents 设置可修改默认值。不支持聊天的代理继续使用终端，API 聊天保持独立。

结构化 Codex 曾因 app.asar 中不完整的原生模块副本而回退。Kotoba 托管时，Windows 进程读取器改为从已验证的 resources/node_modules 加载依赖，保留编译后二进制的创建时间能力检查，不绕过进程所有权证明。

验证覆盖路由、迁移、焦点所有权和显示方式，并提供可选 Windows 原生按键冒烟测试。测试进入实际 Agents 项目、Terminal 1 及 Codex 聊天，执行无害命令、保留未发送草稿、打开模型列表和验证窗口恢复。浏览器注入按键及临时输入框不能作为终端输入成功的证据。付费代理请求、日语输入法组合和未支持的聊天协议不在该验证范围内。

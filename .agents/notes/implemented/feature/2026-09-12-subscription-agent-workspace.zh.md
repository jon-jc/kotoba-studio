# Agent Note：订阅代理工作区

Status: implemented

[English](2026-09-12-subscription-agent-workspace.md) | 中文

## 问题

Kotoba 需要在一个桌面工作流中提供订阅编码代理、独立任务工作树和审查，同时保留完整 API Harness 和双语语音工具。Orca 的 Web 账户 API 未完整实现桌面账户管理。

## 决策

将 Orca 1.4.197 固定为子模块，在临时检出目录构建完整 Electron 界面和原生服务。将所拥有的 Windows 窗口嵌入 Qt。Agents 成为主工作区，API 聊天仍可独立访问。限当前用户访问的命名管道仅接受项目、导航、快照和已审阅草稿操作。管道客户端 PID 和原生窗口 PID 都必须匹配所拥有的 QProcess，回复必须携带每次启动生成的随机标识。

选定的本地工作树更新代码和语音上下文；正在运行的语音任务保留原始根目录。远程路径不会成为本地路径。插入草稿要求兼容且为空的原生聊天输入框，绝不自动发送。底层 CLI 管理自身权限、身份验证和订阅额度。Harness 权限仍独立，Access 按钮跟随当前工作区。

构建覆盖层隔离配置目录，禁用遥测和上游本地更新器，去除重复托盘及窗口控件，保留正常 CLI 启动审批默认值，并应用 Kotoba 外观和语言。保留上游许可文件和运行时依赖资源。打包使用上游原生 PTY 所有权、守护进程加载、CLI 资源和内置插件探针；只有验证通过才发布产物。

## 考虑的替代方案

单独的 Orca 窗口会拆分所要求的工作流。其 Web 客户端缺少原生账户管理操作。重新实现原生代理启动、PTY 和审查代码会重复大量现有实现。通用 JavaScript 桥接会暴露不必要的权限；固定命令词汇已足以共享上下文和审阅后的文本。

## 影响

桌面包含具有不同账户和权限契约的两个代理引擎。订阅代理为主，API 会话保留独立历史。公开 README 在一个文件中包含英语和日语，不再遵循继承的中文配对要求。上游子模块使用自己的 lint 工具链。

## 验证与限制

定向测试覆盖产物路径限制、环境过滤、外部回复和窗口、过期上下文、草稿拒绝、主导航和运行中任务的目录保持。隐藏的 Windows 冒烟测试启动打包后的原生窗口，添加临时 Git 项目，读取选定工作树并拒绝不可用的草稿。未执行付费提供商调用、远程主机、账户配置和外部发布。嵌入运行时当前面向 Windows x64；签名、干净机器资格验证及广泛外部服务覆盖仍属于独立发布工作。

## 嵌入显示修正（0.10.1）

Qt 接管 HWND 后不会更新 Electron 的隐藏窗口合成状态。固定的 `present` 操作只显示已经嵌入且可见的工作区，不激活窗口，同时关闭渲染器后台节流并请求合成帧。原生 Qt 容器将子窗口重新定位到自身原点，并轻微调整尺寸后恢复，以修正 Electron 恢复旧顶层坐标和保留过期画面的问题。隐藏事件也同步到 Electron。重新显示代理页面时再次执行交接。账户导航确认成功并报告失败；首次引导在设置页面暂时隐藏，不会将引导标记为完成。

隐藏的 IPC 冒烟测试无法验证合成像素。`smoke_fleet_display.py` 提供显式启用的 Windows Graphics Capture 检查，使用隔离配置和自有进程清理，验证工作区渲染、账户页面切换、调整尺寸和隐藏后恢复。可选捕获依赖仅用于验证；截图可能包含本地账户标签，因此不提交到文档。

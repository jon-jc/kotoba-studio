# Agent Note: 以对话为中心的桌面工作区

Status: implemented

[English](2026-09-10-desktop-workbench.md) | 中文

## Problem

常驻导航栏和语音配置会与当前任务争夺空间。复制转录后再找到聊天输入框增加了手动步骤，单文件查看器也无法保留多文件比较的上下文。

## Decision

原生外壳使用紧凑工具栏、可选语音面板和底部终端。路由、插件和本地模型仍可通过溢出菜单及命令面板访问。嵌入式对话继续管理会话、凭据、模型选择和智能体执行。

确认后的语音文本通过 Qt 原生粘贴操作进入可见且可编辑的聊天输入框，保留原草稿且不会提交。输入框不可用时，文本留在剪贴板。每个异步交接标识其请求，防止旧回调粘贴新的剪贴板内容。源文件使用带行号和循环搜索的只读标签页；无法读取、二进制或超大文件不会替换已打开的标签页。

## Alternatives considered

**保留两条导航栏。** 重复的常驻导航占据横向空间，使语音面板与任务竞争。紧凑工具栏保留相同入口而无需第二条侧栏。

**替换嵌入式聊天。** 重写对话会分散插件、会话、审批和模型路由的管理。原生外壳支持完整的现有聊天。

**直接写入编辑器状态。** 私有编辑器状态会使桌面依赖输入框实现。原生粘贴遵循正常输入路径，并保留发送前确认的行为。

## Consequences

代码标签页保留阅读上下文，但不会编辑文件或自动重新加载已变更文件。源代码编辑和差异仍在智能体工作区。语音交接使用系统剪贴板；没有可编辑会话时退回复制。原生测试覆盖草稿保留、源文件导航、语言切换及不自动提交；嵌入式浏览器检查覆盖实际组装的编辑器。

# Agent Note: 桌面动效与故障恢复

Status: implemented

[English](2026-09-10-desktop-motion.md) | 中文

## Problem

桌面切换需要保持视觉连续性且不延迟操作，录音或设置失败后恢复控件也必须可用。

## Decision

[动效模块](../../../../python/voice/src/kotoba/motion.py) 为原生语音和终端面板提供短暂的淡入效果。隐藏面板会取消动画并移除临时图形效果。聊天界面通过已有的桌面脚本集成获得按钮过渡和弹出菜单淡入。保存的减少动态效果选项会禁用这些效果，同时遵循 Windows 动画偏好和浏览器减少动态效果媒体查询。网页初始背景与原生外壳一致。

[语音控制器](../../../../python/voice/src/kotoba/desktop.py) 在捕获期间延后刷新提供商列表，清除不可用提供商的显示而不擅自改变保存的选择，并在推理前报告缺失的输入源或空录音。[访问设置对话框](../../../../python/voice/src/kotoba/access_ui.py) 在失败后提供显式重新加载，并在设置操作期间禁用无法执行的控件。

## Alternatives considered

改变停靠面板尺寸的动画会反复调整编辑器和流式聊天布局。永久图形效果会在动画结束后继续增加渲染负担。自动重试设置写入可能在其他客户端修改权限后应用过期选择，因此恢复需要显式重新加载。

## Consequences

淡入期间控件仍可立即操作。原生动效仅作用于应用拥有的面板，避免对 WebEngine 添加图形效果。这些过渡不表示推理进度，也不延迟录音。验证覆盖取消动画、嵌入式浏览器减少动态效果、捕获期间刷新、缺失音频、提供商移除和设置恢复。[Windows 指南](../../../../python/voice/WINDOWS.md#motion-and-recovery) 说明面向用户的控件。

# Agent Note: 桌面访问权限选择

Status: implemented

[English](2026-09-10-desktop-access.md) | 中文

## Problem

桌面用户需要清晰可见的智能体访问权限选择方式，并能区分新会话的默认设置与现有会话已记录的权限。

## Decision

[原生访问对话框](../../../../python/voice/src/kotoba/access_ui.py)提供只读、工作区写入和完全访问预设。作用范围选择器区分单个聊天与新聊天及下一次语音会话的默认值。完全访问需要明确确认。[控制器](../../../../python/voice/src/kotoba/access.py)通过带修订检查的权限设置命名空间保存默认值，通过现有可审计的权限命令改变会话。只有后端接受操作后才显示成功。修改默认值会关闭空闲的语音 SDK 客户端，使新会话读取保存的策略。

## Alternatives considered

仅保存桌面偏好会偏离真实工具策略。一次修改所有会话会默默扩大无关工作的权限。当前没有自动风险审批组件，因此不提供自动风险审核标签，而是说明实际可用的限制。

## Consequences

聊天负责交互式审批；语音 SDK 在无法获得审批时拒绝操作。Windows 主要限制写入，读取、网络及文件系统仍有已记录的限制。手动终端命令和有权限的插件不会因该选择器而受到隔离。对话框说明这些限制，并在拥有设置操作期间阻止桌面听写与应用关闭。[语音指南](../../../../python/voice/VOICE.md#agent-access)说明用户操作。验证涵盖完全访问确认、作用范围隔离、设置修订检查、真实运行时的权限切换及现有文件系统执行器测试。
